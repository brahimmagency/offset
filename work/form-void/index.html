THE IDEA

LET THE SPACE
DO THE TALKING.

Form / Void uses the conventions of architectural publishing rather than the conventions of a typical studio site. Projects are treated like plates in a monograph, with coordinates, measurements and concise captions sitting beside large compositions.

Whitespace is not empty. It is part of the architecture.

The system is intentionally quiet so photography, drawings and project names can create the emotional weight. The grid breaks only when it has something to say.

LAYOUT

STRICT GRID.
SELECTIVE BREAKS.

Technical alignment gives every project a calm base, then a few elements step outside the grid to introduce tension.

VOICE

PRECISION
OVER HYPE.

Short descriptions, project metadata and clean labels keep the copy factual and let the architecture carry the mood.
